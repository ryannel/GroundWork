# GroundWork

GroundWork is a delivery framework for building software with agents. It is
being rebuilt from a ratified specification, and this repository was reset to
a clean slate as part of that ratification.

Where things live:

- `docs/spec/` — what to build. Start at `docs/spec/index.md`.
- `docs/ladder.md` — what to build next, and what "done" means for it.
- `docs/execution-plan.md` — how the rebuild is delivered and proved.
- `CLAUDE.md` — the working agreement: the whole process, on one page.

The old framework lives on the `legacy` branch. It keeps serving its installs
until cutover. Do not read its prose — the working agreement says why.
