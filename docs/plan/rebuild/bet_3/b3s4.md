# Slice 4 — Test markers and the board derivation

The board is a derivation, never a file anyone edits. Three inputs: the sealed plan, git's `Slice:` trailers, and the adapter's per-test results.

A derivation that writes is one small change away from a board a person can move by hand, which is the exact thing the bet's done condition forbids. So one proof fails if any file changes while the row runs.

The marker lives in the Go test's own name, because `-run` filters names and no second file can then drift from it.
