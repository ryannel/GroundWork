# Slice 1 — The plan artifacts and their reader

Every later slice reads these files, so nothing else can be defined until their shape is fixed.

What lands: the three plan shapes, a reader that parses them and holds them together, a `plan` battery row, the first section of the derivation contract, and this repo's own plan written in the new format.

What does not land: any judgment about whether work is done. Landed-ness comes from git and red-or-green comes from the test run, and both arrive in slice 4.

The hostile cases are the point of the proof plan. A parser is only as good as what it refuses, so the table drives duplicate ids, ids outside the charset, wrong types, missing frontmatter, absolute paths, a slice on a milestone its bet does not hold, and a file large enough to be an attack.
