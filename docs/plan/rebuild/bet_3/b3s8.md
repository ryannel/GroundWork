# Slice 8 — The held-out grading run

The sealed fixture set is run once. Grading only, no tuning.

What it grades: a two-milestone bet decomposes, the board starts red for the right reason, three slices land in sequence and each turns exactly its own row green, and the stub check faces the three planted styles.

A finding is filed for every miss and every false red. Any fix is its own slice at a new battery version, and it needs freshly authored fixtures — a graded run burns the ones it read.

This slice claims no facing item. It delivers a grade, not a surface.
