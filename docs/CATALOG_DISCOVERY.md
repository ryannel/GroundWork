# Cataloging a product

Groundwork keeps one current component document per component. A product declares the repositories it owns or uses, optionally narrowed to paths within a monorepo. Components live in the source repository's `.groundwork/catalog/components/<id>.json` by default. A product can explicitly select the same format under `.groundwork/local-catalogs/<repository>/components/<id>.json` in its home when the source is not writable.

Read the product and current catalog with `search_catalog` and `get_catalog_entity`. Inspect the local source checkout at a pinned commit, then write a complete, cited component with `write_catalog`. Supply the latest target `expectedRevision` and `expectedContext`; for a local catalog also supply `sourceRoot`. The write validates source paths, line ranges, revisions, references, and the whole candidate before replacing the document atomically. Review and commit the resulting file through Git.

A component records its APIs, schemas, data, messages, jobs, dependencies, and selected execution flows. `covers` names the paths examined. `areaGaps` has an array for dependencies, API, data, messaging, jobs, and flows; an empty array means no known gap in that examined area. Source evidence identifies a repository-relative path, line or range, claim, and full observed commit SHA. The observation time is separate. See the [catalog skill](../.agents/skills/groundwork-system-catalog/SKILL.md) for the authoring procedure and [current document example](../.agents/skills/groundwork-system-catalog/references/normalized-output.md).

Use `check_catalog_freshness` to compare the observation with a selected local source commit. It reports changed cited files, changed covered files without citations, and files outside every component's coverage. It does not claim the running system is correct. Catalog search uses repository-qualified entity IDs; fetch detail with `get_catalog_entity` and follow its cursor. A missing or partial catalog remains a visible gap and does not block feature planning.
