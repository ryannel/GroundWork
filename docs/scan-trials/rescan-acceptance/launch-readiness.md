## Run the enrichment pass

Use [groundwork-scan](../../../.agents/skills/groundwork-scan/SKILL.md) with the verified source routes.
Run scripted inventory, source extraction and cache/delta checks first. Reuse compatible indexes; read and
parse changed source only, then rebind dependent facts when their inputs change. Use Spring entry tools
and the [C# program workflow](csharp.md) for their supported profiles. Other source forms follow the explicit
canonical capture route with independent review and unresolved obligations.

Parallel work is bounded by runtime component and source pin, with one owner integrating reusable tooling
at a checkpoint. Formatting, lint and deterministic-output checks precede an analysis freeze. Reproduce
new gaps, repair shared tools and retain regressions; do not copy bespoke fixes across repositories or
reinterpret an unsupported pattern as complete. The fixed benchmark and large mutation packs validate
tooling changes and need not be repeated for every routine repository capture.
