## Independent evidence

The generic bounded reader returns actual framework, host and source records. The independent
`tools/scan-spring-review.ts` CLI reconstructs the reviewed document from those pages before checking
19 independently source-read method/path/type expectations. Deleting a route-to-schema reference,
schema declaration, schema-to-route profile or source record rejects the claim; changed prefixes and
return types also fail. External wrappers remain explicitly partial schema shapes without preventing
an answer to Q01's declared-type question.

The final bounded framework review returns all 1,636 records in 409 pages, with four records and
65,536 bytes allowed per page. Its compact responses total 1,228,781 bytes. The retained
[receipt](../../../reports/customer-service-spring-001/review-002/receipt.json) records the snapshot and
[pages](../../../reports/customer-service-spring-001/review-002/pages.json) retain the actual records.

Old trial 005 reader pages were compared with the new capture. Some edge identities changed when
annotation metadata was added, so Q07 and Q08 were replayed against the actual new shards. Q07 returns
221 selected records in 56 pages; Q08 returns 231 in 58. The default-reason checker additionally uses
only those returned native records. Its eight relation-removal mutations reject missing value or
operand structure with display syntax unchanged. These current native receipts are retained under
[native-review/current](../../../reports/customer-service-spring-001/native-review/current/).

Final framework records contain 19 routes, 278 source shapes and 20 security bindings. Nineteen
method policies correctly retain unresolved activation; the remaining binding records the token-header
interceptor. All 17 customer and audit routes link to it; both migration routes fall outside its
`/v1/customers/**` registration. There are no invented explicit path exclusions. Correct nested
`Views.Update` and `Views.Patch` identities remain, and the false package-level aliases are absent.
The snapshot is `e60de201b2821b862fc55ced1d3c9ee70441612ee6b3e6d3ab6bf4ec0a6ade7e`.

All 221 Q07 and 231 Q08 reader records were compared by exact ID and full JSON value with trial 002's
matching shards: every record has the identical full JSON value. The retained
[final equivalence receipt](../../../reports/customer-service-spring-001/native-review/final-equivalence.json)
therefore carries those bounded proofs onto the final capture without pretending their initial replay
ran against a different document.

The source-first audit caught and corrected prototype mistakes before acceptance: regex-based method
body matching could fabricate interceptor evidence; inherited interface prefixes needed their own
sources; and method-security activation differs between PreAuthorize, Secured and RolesAllowed.
The [source review](source-review.md) records the framework/configuration limits. Exact Spring
versions are inherited outside this tree; parent/web dependency version 4.0.48 is not a Spring version.
No Maven build, external dependency fetch or other repository scan was performed.
