## Source behaviours retained

- Authorization reads the cart and may save ownership before returningtrue. Existing owners require both issuer and subject; missing/blank subject is ownerless. A matching access token can claim an ownerless cart for authenticated identity; anonymous token access cannot enter an owned cart. oauth2.enabled=true/default enables method security; false selects the separate permit-all configuration. Invalid present bearer is rejected before GraphQL, but imported issuer/JWK discovery is not a fabricated direct source HTTP call.
- Checkout rejects only CHECKED_OUT and empty lines, not every non-ACTIVE status. CHECKING_OUT save is outside try. Inside try, construct request, remote checkout, CHECKED_OUT save and response projection occur in order. Any try exception attempts FAILED save then rethrows; FAILED save can replace the original failure. Remote success followed by local save failure can leave an order and failed cart. No compensation/atomicity/idempotency implementation is inferred.
- Conditional opportunity enrichment runs before create save only for nonblank opportunityID and missing partner slots. Supplied slots win; missing data and exceptions fall back to supplied values. FakeOfferRestClient ignores token/advancePayment when selecting its fixed classpath fixture.
- Expiry selects ACTIVE by updatedAt cutoff, saves EXPIRED first, then archives. Failure can leave EXPIRED without archive and processing continues. withStatus resets updatedAt, so the independent EXPIRED deletion cutoff is measured from that updated value. Job runs expiry then deletion under an outer catch. Source cron */30 * * * * * is preserved separately from its misleading Every30thminute comment; local profile declares a different cron.
- ConditionalOrderMapper forwards the actual current JWT as customer.userAccessToken only after nonnull customer input. It forwards the selected individual fields and derives organization partnerId from cart buyer, with a partner-only organization fallback. input.type, individual.volvoId, contactPerson and address.state are not all forwarded. Input delivery partner overrides stored partner. Java input.metadata is used although SDL CheckoutInputV2 has no metadata field. SDL/docs Offer conversion, checkout409/resume/idempotency, ACTIVE-only and pricing prose do not replace the actual source.
- InstallationTarget.Vin(String vin) binds the nested String component, not the Vin object. Its source projection is authored independently of Java17 parsing normalisation. Known annotated Vin subtype schema is associated with the interface; the interface's empty own-field declaration is not an empty-payload claim. Cart compact constructor defaults null status to ACTIVE. Immutable with* reconstructors preserve other components and reset updatedAt. Allocation is separate from void constructor execution, including this/super calls.
- Legacy migration fills only missing item IDs under null guards/continue, replaces by _id and ignores result; updatedCarts counts attempts after normal return. New migration requires legacy issuer, first copies existing $buyer.volvoId via pipeline expression into owner.subject and sets issuer under its narrower filter, then separately unsets buyer.volvoId under a broader exists filter. The dollar string is expression intent, not persisted literal data. Partial completion is possible; both rollbacks only log.
