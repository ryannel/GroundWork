# Optimisation API independent source notes

FastAPI mounts a Graphene app at /graphql and health router. Lifespan initialises singleton Application; thread daemon is started by source initialise branch. GraphQL declarations, resolver methods and HTTP mount are distinct registrations. No declared auth wrapper in main. Molytope query permits JWT-only or configRules/paths, rejects absent inputs or mixing JWT with other inputs. JWT branch decodes source token; imported token semantics need exact code. Mutable default arguments are source declarations rather than per-request fresh values. prepare_config_rule filters nested dictionary keys through one allowlist. polytope pair query guard checks both None, not both empty.

Both STORAGE=AZURE and STORAGE=LOCAL construct AzureBlobStorage with different connection configuration; local does not establish filesystem. Other storage value implicitly returns None. Application guards cloud factory only when start_orchestrate true but invokes it unconditionally later. Posterior storage compresses pickled value then default cloud upload pickles those bytes again; get reverses cloud load plus decompression and pickle. has returns data is None. get catches every failure and returns None. Upload source sets overwrite=True, delete is a separate SDK operation. CloudStorage compression attributes are not initialised by Azure subclass **init** because it does not call super, though default noncompressing paths short-circuit their checks; preserve actual path assumptions.

ProblemOrchestrator.solve awaits selected suite.perform, appends completed solution to a process-memory list and returns tuple(suite,solution). Background run sleeps, pops list and invokes gc; it does not store posterior results. Queue append is not broker submission or durable job completion. Configured storage and helper methods do not establish writes from that loop.

ILP wrapper is async but directly executes synchronous cvxopt.glpk.ilp per item; no remote solver service or automatic parallelism. Result conversion occurs for optimal/feasible/undefined. FetchRules builds awaitable helpers and gathers them, but synchronous storage/download/decompress/parse happen inside each. Load errors rethrow; per-rule to_dict errors skip that rule. None storage returns empty. Missing condition/consequence defaults are assigned from exact source rules.

Health returns source tuple(dict,200); framework wire/status behaviour is distinct. Live observations, imported framework scheduling, mutable heap and deployment remain unresolved.
