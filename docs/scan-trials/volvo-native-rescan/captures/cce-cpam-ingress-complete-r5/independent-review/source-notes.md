# CPAM independent source notes

Three executable hosts have explicit constructor wiring. HTTP App uses Azure ReadWriter after required prefix/config validation; local PipelineApp uses filesystem Writer, and its LocalStorage.Read lacks the context argument required by ReadWriter. Do not infer shared concrete bindings globally. Main honours SkipEventReader; Aggregator stores it but Run does not check it. Both readers retain distinct topics/groups/auth policies; imported default/dedupe timing and acknowledgements are gaps.

Six REST routes use source gorilla/mux registrations. Health passes a strings.Reader object to json.Encoder, not an inner literal response DTO. respond/responseText write intended status before encoding/body writes; later500 attempt does not replace committed status. Text content-type literal contains a comma. There is no source authentication wrapper on this router; infrastructure access policy remains external.

Import JSON specMarket/includedModelYears and optional recalc(ParseBool) feed Pno3 lookup; missing years default to source included-year policy. Spec market brand parsing accepts3-byte default or polestar/geely/lynkco underscore variants. R&D6xx defaults2027/2028. Per-brand jobs only submit when selected Pno3 list nonempty; HTTP200 text claiming jobs started does not prove any enqueue or completion. SendMarketAuthJob ignores nil, launches a goroutine then returns; child send canblock on cap100 channel. Run ranges that channel serially and only handles *MarketAuthJob, not declared GlobDictJob. Context cancellation does not itself close the channel.

MarketAuthsUpdated batch handler selects legacy code conditionally, logs import failures and continues; malformed protobuf returns from the whole batch handler. Handler is void, so SDK delivery acknowledgement is not established. Orchestrator uses cached per-hash results when unchanged and not recalculate, otherwise pipeline; fallback recomputes when cache result read fails. OldS3 comments do not override actual Azure storage.

Publishing requires nonempty market and both resultlists. Rules event publishes before components event; second failure can follow first publication. Normal PublishMessage returns marshal error; compressed variant logs marshal error but returnsnil without publication. Both warn on oversized payload and still attempt publish. Caller nil error therefore does not prove a message was submitted or durable.

Blob Write first uploads; only enabled flag plus BlobArchived error triggers DeleteBlob then one retryUpload. Delete can succeed before retry failure. ContainerAlreadyExists is the only ignored create-container error. Prefix/filename are source-composed values; download body closed after ReadAll, listing is paged. Source client result is separate from durability. Local Write may transform configrulesets throughLZ4/protobuf/JSON and recursive type-name replacement; notbyte-identical persistence. mkdir and WriteFile errors are distinct; imported/filesystem semantics remain source boundaries.
