# Optimisation facade independent source notes

Three explicit Fx hosts have separate providers, startup invokes and registrations. Main uses cached filter/CCH/GraphQL wrappers; event uses direct filter service and OptApiBackgroundBaseURL bound as normal GraphqlClient. Main binds OptApiBaseURL to normal and OptApiBackgroundBaseURL to background client. Market mapping registers its own typed command/query handlers. Global generic dispatch keys use reflect.Type of key[Q,R], not merely Q's short name; AddHandler does not return a value. Do not conflate process-memory dispatcher registration with broker subscriptions.

Main common JWT middleware also covers /public, with additional read permission middleware there; Swagger is outside it. Market mapping has common JWT plus explicit read/admin route groups. Event router has no JWT middleware in its source common chain; infrastructure access policy remains unknown. / and /v2 facade closures, /v1 market groups and /v3 policy groups have distinct middleware. Parenthesised route provider results are actual generated handler values, not ordinary HTTP invocations at registration time.

River Enqueue begins tx, InsertTx then Commit, with deferred rollback ignoring ErrTxClosed; source InsertTx result is not commit. Config is MaxAttempts1, JobTimeout5hours and computed river.QueueDefault map key with MaxWorkers; imported runtime policy/key value remain unresolved. Batch dispatch can partially enqueue before later error.

Specification pipeline missing-car fetch returns nil during source transition; denied car also nil-skips. It applies allowed selection rules, obtains or creates stored car, creates new ruleset remotely, calculates start/base configurations, computes requirements then commits local ruleset replacement. It deletes old remote ruleset only after successful local replacement. Earlier writes/new ruleset can survive later failures; no global rollback/outbox is established. RulesetReplacer fluent returns must follow local signatures; no invented void/receiver aliases.

Source generated SDK/gRPC/GraphQL schemas and effective network bindings remain separate. Cached flag evaluation is an unresolved library invocation, not per-call LaunchDarkly reachability.
