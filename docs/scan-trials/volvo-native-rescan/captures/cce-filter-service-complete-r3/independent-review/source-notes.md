# Filter independent source review

Actual await/run/gather activation must be separate from coroutine construction. Eight type-header handlers across four subscribed topics do not establish topic/type pairings. Source exceptions, normal returns and consumer commit conditions must remain explicit.

Health does not contact the database; readiness does. The readiness handler raises503 inside a broad exception wrapper that attempts500, so declared503 is not a guaranteed effective result. includeParents is declared but unused. Policy PUT lookup occurs before its local try. Components save protects legacy values by filtering desired/current sets before delete/update/add.

Producer callbacks log errors without changing the local error variable; flush return is ignored. Normal handler return can reach source commit; this is not synchronous durable broker acknowledgement. Event.key uses metadata.type_name plus caller key; supplied metadata can override constructor type for headers, topic and key. Azure compression verification references undefined set_compression and may fail before its intended exception. Context-exit imported database policy remains distinct from cursor.execute acknowledgement.

Dockerfile and compose declarations do not conclusively establish worker activation: compose command does not override the image entrypoint. Local source declarations and deployment are separate.
