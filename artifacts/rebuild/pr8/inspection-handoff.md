# Native inspector

The inspector reads the supplied before/after indexes and actual plan metadata. It preserves the exact raw record, all incoming and outgoing references, explicit ownership separately from placement, declared interface providers, implementation gaps, proposed-effect gaps and direct operation attribution. Before inspection of an added fact returns no current fact. Evidence records resolve through their actual recorded repository pin and retain their supporting evidence ids.

`modelInspectionOf(context, id, version)` supplies one serialisable inspection for server and browser consumers. `modelInspectionRecords(context)` supplies non-evidence native records, removed ids and actual plan metadata for the palette. The shared chip helper is re-exported; vocabulary is owned by `model-chip.ts`.
