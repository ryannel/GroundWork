## PR 9 scan replacement

The scan workflow uses discovery inventory to build `inventory.json`, `packets.json`, `inputs.json` and a digest-pinned `publication.json` from an explicit capture and clone. It runs no model calls. The legacy refresh skill still runs scan-diff, scan-mark and scan-status. Scan-diff reads a mark and invokes the source checker for a refresh list. Scan-mark uses the same subprocess to pin cited Git blobs before writing a mark. Scan-status reads the authored system repository list and scan marks, then optionally records a check. These raw reads belong to the scanner workflow. PR 9 replaces the workflow and updates its skill commands. The old marks stay until PR 10.

The source checker is a separate current proof consumer. Its native path and retained format-1 scan support are covered by [the source checker proof](sources-cli.md).

## PR 10 old schema retirement

The discovery validator takes explicit inventory, interpretation, inputs and discovery files. It verifies the optional review and prints a validation receipt. The interpretation validator takes a sidecar and digest-pinned input manifest. Readiness uses the same interpretation reader. The generators emit TypeScript from the named old schemas. The knowledge validator is still a real command for arbitrary supplied bundles and may write an explicitly requested snapshot. Its source checker verifies pinned paths in a clone. Keep these old contracts and their toolchain until the PR 9 scanner replacement passes and PR 10 proves removal of the old schemas.

The interpretation format helper is shared with explorer visual interpretation. Its disposition needs both dependency proofs.

## PR 10 explorer retirement

The documented publication workflow builds, refines, repairs, packs and installs a retained corpus. Publication reads the canonical current index to label components. The remaining publication steps use named corpus or generated explorer files and retain their checked pages and manifests. Installation places the generated bytes under `explorer/corpus/<generation>`. PR 10 owns retirement after the recorded explorer parity proof, with no unexplained items. The stages in the packet leave these producers available.

Explorer visual-input and capture replay helpers have several proof and export callers. This packet leaves them for a separate caller-by-caller review. It does not classify a standalone proof entry based solely on the absence of a package command.
