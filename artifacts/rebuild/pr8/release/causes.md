The frozen snapshots are still the comparison inputs. Each release receipt gives the route, both snapshot hashes, the before and after status and media type, observed bytes, exact heading, link and inspection ID additions and removals, and both visible text hashes. A new route is selected in addition to the full frozen set. A shifted array pointer can contain two unchanged members because the capture compares ordered arrays. The receipt's membership delta distinguishes that shift from an added or removed link, heading or identity.

The link, plan and Range reviewers check the captured destinations and source records separately. The comparison accepts exact workspace, file, pointer, before hash and after hash tuples. An unrecognised field or an altered value requires a fresh disposition.
